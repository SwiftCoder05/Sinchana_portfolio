# Sinchana S — Portfolio

Personal site for **Sinchana S**, Software Engineer in Bengaluru.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Replace the portrait

Drop your photo here:

```
public/profile.jpg
```

Use a vertical portrait if you can (roughly 4:5). The crop is editorial — head toward the top third — so a casual LinkedIn crop will look tight.
